# Slow Rise Coffee Co. — landing page

React + Vite, smooth scrolling with Lenis, animation with GSAP (ScrollTrigger), and text effects from ReactBits
(SplitText, ScrollReveal, CircularText, ScrollVelocity — in `src/components/reactbits`).

```bash
npm install
npm run dev
```

Placeholders to replace before launch: prices, opening hours, the street (Willow Lane, Old Town), the three farm
names, and the photos (stand-ins from Wikimedia Commons, credited in the footer).
